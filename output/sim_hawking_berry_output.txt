  ANALYSIS: BERRY PHASE RATIO AT HORIZON
======================================================================

  phi(r_s) = PHI_MAX * a_0/2 = 0.605232
  phi(r_s)/PHI_MAX = a_0/2 = 0.153850
  This is the SAME ratio as r_p/r_s — the geometric invariant.

  gamma(r_s) = -0.898959
  gamma_0 = -1.025362
  gamma(r_s)/gamma_0 = 0.876724

  a_0/2 = 0.153850
  (1 + a_0/2) = 1.153850
  gamma_ratio / (1+a_0/2) = 0.759825

======================================================================
  KEY OBSERVATION: phi(r_s) IS M-INDEPENDENT
======================================================================

  phi(r_s) = a_0 * M / r_s = a_0 * M / (2*G_eff*M) = a_0/(2*G_eff)
           = 0.605232
  This is FIXED. Does not depend on M.
  Therefore gamma(r_s) does not depend on M either.

  But T_H = 1/(8*pi*G*M) DOES depend on M.
  So T_Berry = |gamma(r_s)|/(h*2*pi) is M-INDEPENDENT.
  This seems wrong...

  RESOLUTION: the Berry phase gives the TEMPERATURE SCALE,
  but the M-dependence comes from the NUMBER OF MODES
  at the horizon. T_H = T_scale / N_modes(r_s).
  N_modes ~ r_s^2 ~ M^2. But T_H ~ 1/M, not 1/M^2.

  Better: kappa_Berry should be per unit AREA, not per cycle.
  kappa per unit area = |gamma(r_s)| / (h * 4*pi*r_s^2)
